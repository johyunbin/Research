### B5. 결과
- RQ 정렬: RQ1 은 네 클러스터 + (A4) 비합성 도메인 서술 종합, RQ3 은 절대 편수 대신 **시기별 비율**(G3 17%→29%, G1 61%→56%, G2 48%→40%)과 병용 비율, RQ4 는 결과 절에 레버 도출 결과를 두고 논의에서 해석하는 구성을 검토.
- 역방향의 두 유형 구분(M2): (i) 활동 → 음향 결과, (ii) 활동·동행 → 지각 평정. 연구 단위 비율(33/90 = 37%)도 함께 보고.

- 사회적 상호작용의 취약성 서술 정정: "인용 추적 연구 한 편 탓"(4.2, 4.6) → "한 편씩 제외한 네 분석 중 세 분석에서 유의성 유지 안 됨".
- 표·그림 정합: Table 1 설계·세팅 분류가 Table B1·원자료와 다름 ✔(Table 1: 혼합 34·설문 25·현장관찰 7 / 원자료: 혼합 32·설문 21·관찰 12·질적 8), 전문 미확보 합계 122 vs 124 ✔(보조 색인 사전 배제 2건 누락), 증거 지도 '기타' 범주 누락 ✔, 3.2 "나머지는 비참가자 단위"(실제 6편 + 미보고 36편), 두 경로 모두 2,073건은 우연의 일치 ✔(흐름도 주석 권장).

### B6. 논의
- **구성(LUP 관행)**: 주요 결과 요약(RQ 순) → 선행 리뷰·연구와 비교 및 기전 → 이질성과 해석상 유의점 → 개념 틀의 위상 → 계획 함의 → 한계 → 연구 의제. 현재 4.1(개념 틀)로 시작하고 선행연구 비교·기전 설명이 거의 없다([14] 군중–사건성, [15] 신체활동 결론과 비교 부재).
- **개념 틀(Fig. 8) 위상**: 관여의 경사 5범주는 코딩한 5도메인과 다르고 조절요인은 코딩하지 않았다 → 문헌 기반 개념 모형이라고 명시하고 경로별 근거 수준을 표시하거나, 회피·전유 관련 주장을 삭제.
- 4.2(RQ4 제목)에 RQ1 해석 세 문단이 들어 있음 → 소절 재배치, "세 가지를 짚어 둔다" 삭제.
- 4.3: "흔히 제시되는 두 가지 처방"에 인용 필요, "지지되지 않았다"와 "검정되지 않았다" 구분, 발성 노력 산술(1 dB당 0.25점)은 단일 연구라 지침처럼 쓰지 않기, "가장 방어 가능한"은 실행 비용 기준임을 명시하거나 삭제.
- 4.4·4.5: 보고 표준화 권고 중복 통합, 4.5 여섯 항목을 2–3문단으로 묶고 근거 없는 평가어("투입 대비 효과가 큰") 삭제, "인원 밀도로 음압을 예측하는 식"에 인용.
- 4.6 한계 추가: AI 보조 선별, 데이터베이스 경로 전문 미확보(A2), 학회 발표문 제외, 계획 근거 강도의 1인 판정, 저자 본인 연구 포함, 클러스터 내 구성개념 이질성. 한계는 연구 의제 앞에 둔다.

### B7. 결론
