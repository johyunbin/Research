# Paper32 — OpenAlex 보조검색 갈래 (등록 세 번째 식별원)

등록 프로토콜은 OpenAlex를 보조 식별원으로 명시했으나, 3-DB 풀에 없는 고유분이 **스크리닝되지 않은 채 남아 있었다**(자체 감사에서 발견). 뒤늦게 전수 이행한 결과다.

## 흐름

```
  OpenAlex 고유 레코드 ...................... 352
  기존 풀·인용추적·코퍼스와 중복 제거 ....... −23
                                              ↓
  제목·초록 스크리닝 ........................ n = 329
  배제 ...................................... −314
    비실증(서평·사설·논평·에세이) ............. 147
    관찰가능 행태 아웃컴 없음 ................ 46
    동물·생물음향 ....................... 39
    주제 무관 ......................... 31
    세팅 부적합(실내) .................... 27
    음환경 변수 없음 ..................... 12
    언어·문헌유형 부적합 ................... 12
                                              ↓
  전문 확보 대상 ............................ n = 15
  문헌유형 사전 배제 ........................ −2  (업계지·코칭 뉴스레터)
  미확보 .................................... −8
                                              ↓
  전문 평가 ................................. n = 5
  배제 ...................................... −3
                                              ↓
  포함 ...................................... n = 2
```

## 결과 해석

**이 갈래의 산출은 2편이며, 메타분석에는 한 편도 기여하지 않는다**(둘 다 질적·서술 연구이고 검정통계가 없다). 그럼에도 이행한 이유는 등록한 식별원이기 때문이다.

배제 사유 구성이 이 풀의 성격을 보여준다. **비실증이 147건(45%)** 으로 압도적인데 서평·사설·논평·부고까지 포함된다. OpenAlex가 WoS·Scopus·PubMed보다 훨씬 넓게 색인하므로, 3-DB에 없다는 것이 곧 '누락'을 뜻하지 않는다는 경험적 근거다.

**문헌유형·언어 확인이 결정적이었다.** 전문 확보 5편 중 2편은 OpenAlex 메타데이터가 `language=en`이었으나 실제 본문이 한국어·일본어였다(영문은 제목·초록뿐). 메타데이터만 믿으면 등록 언어 기준을 어길 뻔했다.
