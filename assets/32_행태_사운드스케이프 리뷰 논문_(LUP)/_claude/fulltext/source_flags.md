## C-2. 인용추적 갈래에서 추가된 플래그 (2026-08-03)

- **CT0007 ↔ ID 761 — 표본 중복 의심(MA 독립성)**: Fang et al. 2023(*J. Outdoor Recreation and
  Tourism*, n = 2,034)과 기존 포함 ID 761(2021, *Forests*, 중국 도시휴양림, n = 2,034)의
  **표본 크기가 정확히 일치**한다. 제목·저널·연도가 다른 별개 논문이라 중복 출판은 아니지만
  동일 설문 데이터의 분할 보고일 가능성이 크다.
  → **서술 종합에는 둘 다 유지**하되, **같은 MA 클러스터에 둘 다 효과크기를 내면 안 된다.**
  풀링 시 한 편만 채택하거나 논문 내 평균으로 합성(`analysis_rules.md §3` 확장 적용).
- **CT0126 ↔ CT0322 — 동일 표본 확정(MA 독립성)**: 둘 다 Barrigón Morillas 그룹의 스페인 Cáceres
  연구로 **보행자 105명·29개 가로라는 동일 데이터셋**을 다르게 분석한 두 편이다
  (2022 *Sci Total Environ* / 2024 *Applied Sciences*). 상관계수도 거의 같다
  (LAeq 기준 d 0.63 vs 0.64, e 0.65 vs 0.71). **상관 클러스터(MA4)에 둘 다 넣으면 안 된다** —
  한 편만 채택한다. 채택 기준: 더 직접적인 대비를 보고한 쪽.
- **CT0335·CT0356 — 본문 절단으로 행태 통계 미확보**: 각각 §6.2·결과 후반이 텍스트 추출 한도에서
  잘려 효과크기가 `NR`. 풀링 대상으로 쓰려면 원문 PDF 재확인 필요.
- **CT0090 — Exp2 검정통계 미확보**: 결과절 절단으로 Table 3 평균만 확보.
- **CT0220 — 청각 단독 경로계수가 Figure 6에만 존재**: 본문 수치 없어 집계 다감각 간접효과만 기재.
