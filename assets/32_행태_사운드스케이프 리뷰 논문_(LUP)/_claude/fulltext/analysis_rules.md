# Paper32 — 메타분석 사전규칙 (Analysis Decision Protocol)

작성 2026-08-03 · OSF 등록(osf.io/7ew8q) Synthesis plan의 실행 세칙. 계산 착수 전 확정 —
이후 변경은 사유와 함께 본 문서에 추가 기록(등록 이탈 방지).

## 1. 효과크기 지표

- **집단 대비(음환경 조건 A vs B)** → Hedges' g (소표본 보정 J 적용)
  - M±SD+n 보고 시 직접 계산
  - t(df) → d = t·√(1/n1+1/n2) · F(1,df) → t=√F (부호는 평균 방향)
  - χ²(1)·2×2 빈도 → OR → d = ln(OR)·√3/π
- **연속 연관(r, rho)** → Fisher-z (풀링 후 r로 역변환 보고). rho는 r 근사로 취급하되 민감도에서 제외 검토.
- **회귀계수**: 표준화 β+SE → 부분상관 근사(주의 라벨), 비표준화 B는 SD 정보 있을 때만. 그 외 서술 종합.

## 2. 대비 프레임(방향 규약)

두 하위그룹으로 분리 풀링:
- **(N) 부정 음환경 대비**: 소음·교통음·고레벨 vs 조용/대조 — g>0 = 해당 행태 증가
- **(P) 긍정 음환경 대비**: 자연음·새소리·물·음악 vs 대조 — g>0 = 해당 행태 증가
클러스터별 행태 부호: movement-speed(+=빠름), staying(+=오래/많이 체류), social(+=상호작용 증가).
※해석 시 "빠른 보행"은 회피가설상 부정 신호일 수 있음 — 부호는 기계적으로, 해석은 서술에서.

## 3. 논문 내 다중 효과 처리

- 클러스터×대비프레임당 **논문 1효과** 원칙.
- 선택 우선순위: ①가장 직접적·객관적 측정(관찰>자기보고) ②주분석(primary) ③전체표본.
- 동급 다중이면 논문 내 평균 g(효과 간 상관 r=0.5 가정 Borenstein 합성) — 선택 내역은 ma_input의 selection_note에 기록.

## 4. 표본 크기 규칙

- **유사반복(pseudoreplication)**: 참가자 n을 사용(관측 n 아님 — 예: ID 617은 27명·구간반복). 관측 n밖에 없으면 민감도 전용.
- n 미보고 → MA 제외(서술 종합), source_flags §B 목록 유지.
- ID 7(1978 스캔본)·ID 53(OCR 특수문자)은 수기 원문 대조 후 입력.

## 5. 변환 불가 처리

- 옴니버스 F(분자 df>1) 단독 → 미변환(사후 pairwise 있으면 그것 사용).
- SHAP·변수중요도·ML 지표(1110·1115·1174·1306) → 서술 종합 전용.
- Kruskal-Wallis/Mann-Whitney → U+n 완비 시 r 변환, 아니면 제외.

## 6. 풀링 모델

- REML 랜덤효과 + **Hartung-Knapp** 보정(소규모 k 대비). 이질성 τ²·I²·95% CI 보고.
- k<5 클러스터는 풀링하되 "탐색적" 라벨. 하위그룹: 세팅(공원/가로/광장)·설계(현장실험/관찰)·측정세대.
- 민감도: ①leave-one-out ②low-confidence 제외(858 등) ③관측 n 기반 재계산 ④rho 제외.
- 출판편향: k≥10 클러스터만 funnel+Egger, 그 외 서술.

## 7. 소프트웨어
