## 단계

### 0. 기준본 동기화 (선행)
- ver7 사용자 변경 5건을 md 에 옮기고, ver7 을 서식 템플릿 ver3 으로 삼아 빌드가 ver7 과 같게 나오는지
  요소·표 칸 단위로 대조(지난 ver6 방식). 커밋.

### 1. 비교 기준 — LUP 리뷰 논문 관행표
- LUP 최근 체계적 문헌고찰·메타분석 4–6편 선정(OpenAlex 메타데이터로 후보 목록 → 주제·방법 근접도 순).
  전문은 오픈액세스본만, 내려받기 전에 파일명·출처·크기를 알리고 허락받는다(또는 사용자 제공).
  기존 예시 Zhang et al. (2025) 포함.
- 관행표 항목: 제목 형식 · 초록 구성 · 서론 길이/문단 수/목적 진술 방식 · 방법 소절 · 결과 배열 ·
  논의 구성(주요 결과 요약 → 선행연구 비교 → 함의 → 한계 → 후속 연구) · 결론 길이 · 표·그림 수 ·
  계획 함의 제시 방식 · 부록/보충자료 활용 · 단어 수.

### 2. 분량 예산과 전체 구조
- LUP Guide for Authors 원문에서 단어 수 규정(무엇이 포함되는지: 참고문헌·표·캡션·부록)을 브라우저로 재확인.
- 절별 영어 단어 수 추정 → 관행표 대비 예산 배분 → 줄일 후보 목록(중복 서술, 표와 본문 수치 중복,
  논의 4.4·4.5 길이, 부록 B 위치, 포함 연구 참고문헌 처리 등). 구조 결정은 사용자 확인 사항으로 올린다.

### 3. 절별 내용 검토 (주장–근거–논리)
- 제목: 내용과 일치하는지, LUP 제목 관행.
- 초록: 배경–목적–방법–결과–결론 구성, 250 단어 이하 추정, 수치·표현이 본문과 일치.
- 서론: 논증 사슬(계획에서 소리 → 지각과 행태의 간극 → 측정 발전 → 역방향 경로 → 선행 리뷰의 공백 →
  기여·RQ) 각 문단의 역할, 논의와의 중복, 주장마다 인용 뒷받침.
- 방법: PRISMA 2020 체크리스트(본문 27항목·초록 12항목) 항목별 대조, OSF 등록과의 일치, 재현 가능성.
- 결과: RQ 순서와의 대응, 사실만 보고, 표·그림과 본문 중복, 수치 대조(verify_manuscript).
- 논의: 주요 결과 요약 문단의 필요성, 선행 리뷰·연구와의 비교, 해석 강도(자료가 허용하는 수준인지),
  계획 함의의 구체성, 한계의 완결성, 연구 의제 분량, 결론과의 중복.
- 결론·선언부: 새 정보 없음, 초록과 일치. 하이라이트(3–5개, 85자 이하)·키워드 초안.
  Elsevier 생성형 AI 선언 여부는 사용자 결정 사항으로 올린다.
- 공통 점검:
  - RQ1–RQ4 ↔ 방법 ↔ 결과 ↔ 논의 ↔ 결론 대응표
  - 용어 일관성(순방향/역방향, 클러스터 이름, 계획 근거 강도, 관여의 경사)
  - 수치 일관성(초록·결과·논의·결론·표·그림)
  - 인용 점검(핵심 주장과 인용 문헌 내용의 일치 표본 확인, 빠진 핵심 선행 리뷰)

### 4. AI 투·서술 방식 점검
- 메모리 목록(격언식 결론, 수사 의문, 요약 선언문, 굵은 강조, 잘게 나눈 문단 등) + 구조 수준 패턴
  (기계적 첫째/둘째/셋째 나열, 대칭 문장 반복, "짚어 둔다" 같은 메타 서술, 과도한 연결어·헤지)을
  문장 단위로 표시. 기계 검색 + 사람 읽기 병행.
- 영문화 대비: 한국어 문장 구조가 번역 후 AI 투가 되기 쉬운 곳 표시, 영문 표현 뱅크 갱신 후보.

### 5. 독립 검토
- 맥락이 없는 검토 에이전트 2개에 심사자 역할을 맡긴다: 계획·조경 관점 심사자, 체계적 문헌고찰·메타분석
  방법 심사자. 각자 LUP 심사 보고서 형식으로 작성.
- Codex(헤드리스)로 수치·논리 일관성과 PRISMA 체크리스트를 교차 확인.
- 결과를 하나의 이슈 목록으로 통합: 위치 · 근거 · 수정안 · 심각도(반드시/권장/선택).

### 6. 보고 → 사용자 결정 → 수정
- 검토 보고서(절별 이슈표 + 분량 예산 + 결정 필요 항목)를 사용자에게 제시.
- 승인된 수정만 md 에 반영 → 재빌드(서식 ver3 유지) → 수치·인용·서식 대조 → 독립 게이트 → 커밋.
- 영문화 준비물: 용어집·표현 뱅크 갱신.
